# 🍟 Patat

Gezinsapp om snacks bij de patat te bestellen: iedereen bestelt op zijn eigen apparaat, de snackbakker ziet wat er gebakken moet worden (welke snacks samen in het mandje kunnen) en beheert de voorraad.

- Live: https://patat.vloo.nl
- Blazor WebAssembly (.NET 11), geen eigen server: apparaten synchroniseren peer-to-peer via Trystero.
- Specificatie: [SPEC.md](SPEC.md)

## Lokaal draaien

```
dotnet run --project Patat/Patat.csproj
```
